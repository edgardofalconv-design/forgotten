# FORGOTTEN — primera prueba

Entrega del ZIP existente, sin reconstruir ni modificar el juego.

[Descargar Forgotten-Primera-Prueba.zip](dist/Forgotten-Primera-Prueba.zip?raw=true)

1. Descarga y descomprime el ZIP.
2. En Roblox Studio, usa **Archivo → Abrir desde archivo** y selecciona **Forgotten.rbxlx**.
3. Pulsa **Play/F5**, elige un superviviente y pulsa **PROBAR SOLO**.
4. Para probar persecución, usa **Test → Server & Clients**, con tres clientes.

El ZIP incluye la guía y el informe de comprobaciones. Las pruebas locales de lógica y estructura pasan; la ejecución real en Roblox Studio sigue pendiente. Hay modelos provisionales identificados y audios pendientes.
